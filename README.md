# Deep Learning Basics

A collection of Jupyter notebooks covering foundational deep-learning concepts and common neural-network architectures.

## Notebooks

- `Tensorflow_basic.ipynb` — TensorFlow fundamentals
- `Keras_Sequential_Model.ipynb` — Keras Sequential API
- `Keras_Functional_Model(Mnist).ipynb` — Functional Keras model with MNIST
- `CNN(Cifar10).ipynb` — Convolutional neural network with CIFAR-10
- `RNN_LSTM.ipynb` — Recurrent neural networks and LSTM
- `Simple_AutoEncoders.ipynb` — Basic autoencoder implementation

## Getting started

Install Jupyter, TensorFlow, NumPy, and Matplotlib, then open a notebook and run its cells in order.

## Purpose

This repository is intended for learning and experimentation with core deep-learning workflows.
